## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad, **no abras un issue público**.

Envía un email a **blascooscar36@gmail.com** con:

- Descripción del problema
- Pasos para reproducirlo
- Impacto potencial

Recibirás respuesta en un máximo de 48 horas.

## Buenas prácticas al usar este framework

- Nunca subas `configurar.php` con credenciales reales al repositorio
- Usa variables de entorno para datos sensibles en producción
- Activa HTTPS en producción
- Mantén PHP actualizado a la última versión estable
